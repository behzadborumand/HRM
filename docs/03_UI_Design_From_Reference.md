# طراحی UI بر اساس نمونه‌های BambooHR

بر اساس فایل‌های HTML در پوشه E:\Projects\Save site

## صفحات کلیدی
- Power Edit.html: ویرایش گروهی اطلاعات کارکنان
- Personal2.html / Personal_files: اطلاعات شخصی کارکنان
- Time Off.html: مدیریت مرخصی
- Training.html: آموزش‌ها
- Reports.html: گزارش‌ها

## پیشنهاد ساختار UI برای HRMS_BHR
- داشبورد (Dashboard)
- کارکنان (Employees) - لیست + پروفایل
- اطلاعات شخصی (Personal)
- شغل و سازمان (Job)
- مرخصی (Time Off) - درخواست، تراز، سیاست‌ها
- مدارک (Documents)
- آموزش‌ها (Training) - واگذاری دوره، ثبت انجام، کاتالوگ دوره‌ها (فاز ۱۵)
- گزارش‌ها (Reports)
- تنظیمات (Settings)
- مدیریت کاربران/نقش‌ها

## پیشنهادات فنی
- استفاده از Bootstrap 5 یا TailwindCSS
- جداول با فیلتر/جستجو
- فرم‌های ویرایش
- منوی ناوبری شبیه BambooHR
- پشتیبانی از RTL در صورت نیاز
