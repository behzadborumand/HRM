## Global Constraints

- Preserve RTL and Persian copy.
- Preserve existing routes, field names, handlers, authorization, and data behavior.
- Show only implemented destinations in navigation.
- Keep responsive layouts, keyboard focus, and accessible labels.
- Use the repository's licensed local Vazirmatn asset.

## Review Focus

- Unauthenticated login has no inaccessible app navigation.
- Employee filtering and paging preserve query and department.
- Empty employee results have a useful next action.
- Employee profile has only functional links.
- Narrow screens have no page-wide horizontal overflow; wide tables scroll within their container.
